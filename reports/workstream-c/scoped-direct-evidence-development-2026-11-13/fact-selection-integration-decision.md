## Proposed implementation

Use a private, versioned fact-selection response in a separate opt-in integration. The mapper assigns one decision per requested fact and separates direct spans from context. The application validates the decisions and gives the composer only the selected facts with their context. It projects the final brief through the existing citation and approval controls. The sequential path and public response schema stay as they are.

The compact schema is promising for request size on the consumed meter example. Before freezing a diagnostic, reproduce application-side equivalents for the active geography and branch coverage checks and measure admission on the entire proposed pool. A valid fact ID and exact quotation still cannot prove that a claim answers its slot. Exact-source assessment remains mandatory. [Prototype evidence and limitations](fact-coverage-contract.md)

## Decision

**Recommended:** implement the private fact-selection contract offline. Use the preserved cq1-a20 failure and unrelated synthetic examples in fixed-response tests. Retain the approved owner wording as editorial evidence only. Do not give reference answers or a case-specific subject alias to the mapper.

**Alternative:** keep the current contract. The existing report remains a failed qualification. The tested prompt-only changes and omission fallback do not provide a new basis for running the same qualification again.

This choice covers offline design and implementation only. The next actual diagnostic would need a frozen revision and explicit run grant. The existing CQ1 roster and failed runs remain historical evidence.
