Questions, branch plans and scope sidecars for those eighteen are exact copies. Their source corpora retain the original hashes. Consumed cq1-a27 and cq1-a28 remain excluded.

The isolated 3 and 5 before those row values are source footnote markers. They are not generation amounts. New required facts are predeclared in the pinned case references and are excluded from model inputs.

Petroleum liquids, petroleum coke and other biomass waste were considered and excluded because earlier case manifests already declared them. Exact replacement question strings were absent from the retained case manifests checked during freezing. The EIA source documents and their table context are familiar from earlier development. This is a bounded question-holdout evaluation. It does not establish performance on unseen source documents or production workloads.

All twenty mapper inputs passed socket-blocked admission without generation. The largest reserved request is 3,544/4,096 tokens. Admission measures request fit and source/plan integrity. It does not establish mapper selection quality, composition completeness or final safety. Runtime code was not tuned against these replacements after freezing.

Thresholds stay 9/10 complete supported answerable results, 2/2 partial, 4/4 missing, 2/2 conflict, 2/2 injection and zero critical errors. Each case has one attempt, four main calls, one NeMo wrapper invocation and 180 seconds including preparation. No retries or warmups. Source adjudication must precede the next case. Technical/critical failure, a failed full-pass category or a second noncritical answerable miss closes the batch.
